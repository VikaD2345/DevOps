# Мой пет-проект

Идея: консольное приложение «СтудБюджет» для учёта расходов студента. Можно добавлять траты по категориям (еда, проезд, учёба, общежитие), смотреть сумму за неделю и экспорт в CSV.

Стек: Python 3.12 / SQLite / argparse / Docker

Цель: научиться проектировать маленький CLI-сервис с хранением данных и потом упаковать его в контейнер на следующих занятиях
