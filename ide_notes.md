# Git в VS Code vs терминал

## Что удобнее в VS Code

1. Подсветка diff прямо в редакторе: сразу видно плюсы и минусы, не нужно читать сплошной текст `git diff`.
2. Можно просмотреть историю файла и быстро вернуться к нужному коммиту через интерфейс.
3. GitLens показывает автора строки без отдельной команды `git blame`.

## Что удобнее в терминале

Сложные операции вроде `rebase -i`, `cherry-pick` и работа по SSH на сервере. Там нет VS Code, поэтому эти вещи надёжнее делать в CLI.
# Git в VS Code и в терминале

## Что удобно в VS Code

1. Панель Source Control сразу показывает список изменённых файлов и можно открыть diff одним кликом.
2. Встроенный редактор конфликтов подсвечивает обе стороны merge и позволяет выбрать фрагмент без ручного удаления маркеров.
3. Расширение GitLens показывает автора и дату правки у каждой строки (визуальный `git blame`).

## Что удобнее делать в терминале

Интерактивный rebase (`git rebase -i`), `cherry-pick`, `reflog` и работа по SSH на сервере: в IDE эти операции спрятаны или недоступны, а на удалённой машине часто есть только терминал.
